Privacy Policy for mpvEx

This document outlines the privacy practices and data handling policies of the mpvEx (mpvExtended) media player application for Android.

Application: mpvEx (mpvExtended)
Package ID: app.marlboroadvance.mpvex
Effective Date: September 27, 2026
License: Apache License 2.0
Summary of Core Principles

mpvEx is open-source software engineered with strict user privacy principles:

  • We collect zero personal data, usage telemetry, or device identifiers.
  • The application contains no advertisements, analytics SDKs, or third-party tracking components.
  • Media playback, file indexing, and playback history remain strictly on your local device.
  • All operations are transparent and verifiable via our public source repository.

1. Overview and Scope

mpvEx ("the Application", "we", "us", or "our") is a free and open-source media player developed on the libmpv media playback engine. This policy applies to all official builds of mpvEx distributed through GitHub, Google Play, and verified third-party repositories.

The Application functions as a client-side media player utility designed to render user-provided audio and video files. We do not operate user accounts, cloud storage, or user analytics infrastructure.

2. Information Collection and Telemetry

mpvEx does not collect, record, transmit, or monetize any user data. Specifically:

  • Personal Identifiable Information (PII): No names, email addresses, contact details, account credentials, or payment information are ever requested or gathered.
  • Device and Network Identifiers: We do not capture device IDs, IMEI numbers, Android IDs, advertising IDs (AAID), MAC addresses, or IP addresses.
  • Analytics and Usage Metrics: The Application does not integrate any telemetry libraries, crash reporting services (e.g., Firebase Crashlytics), or analytics frameworks (e.g., Google Analytics).
  • Media and File Content: Your personal media files, playback queues, and storage folders are never accessed for surveillance, profiling, or transmission.

4. Local Storage and Data Retention

All application state, user preferences, and playback history are stored exclusively in private local databases on your device:

  • Playback Progress and History: Stored locally using SQLite/Room to enable automatic playback resumption and recent files listings.
  • Configuration Preferences: Subtitle styling, gesture settings, decoder choices, and mpv script parameters are stored in Android DataStore.
  • Data Removal: Playback history can be cleared at any time from within the Application settings. All stored application data can be removed immediately by selecting Clear Data under Android system settings or by uninstalling the Application.

5. Network Streaming and External Servers

When you choose to play a remote media stream or connect to a network share:

  • Network requests are made directly between your device and the remote host server specified by you.
  • The Application does not route traffic through any intermediate proxy, tracking server, or relay.
  • Your communication with remote servers is subject to the privacy terms and policies of the respective service provider.
  • Authentication credentials entered for local shares (SMB, FTP, WebDAV) are stored locally on your device and transmitted solely to the target host.

6. Crash Diagnostics and Support

If an application error occurs, mpvEx presents an on-device error dialog (CrashActivity) displaying the stack trace.

The Application does not automatically transmit crash logs over the network. If you choose to submit a bug report via GitHub Issues, you do so voluntarily and have the ability to review, edit, or redact sensitive pathnames or file information prior to posting.

7. Children's Privacy

mpvEx is a general-utility software application. We do not knowingly solicit, collect, or process data from children under the age of 13 (or under 16 within the European Union). Because the Application collects no personal data whatsoever, it is compliant with the Children's Online Privacy Protection Act (COPPA) and General Data Protection Regulation (GDPR).
